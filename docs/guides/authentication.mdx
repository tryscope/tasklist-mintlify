---
title: "Authentication"
description: "Every request carries a bearer token."
---

The API authenticates with a bearer token in the `Authorization` header. Tokens are created on the account settings page and do not expire until you revoke them.

<Tabs>
  <Tab title="curl">
    ```bash
    curl https://api.tasklist.example/lists \
      -H "Authorization: Bearer $TASKLIST_TOKEN"
    ```
  </Tab>
  <Tab title="JavaScript">
    ```javascript
    const response = await fetch("https://api.tasklist.example/lists", {
      headers: { Authorization: `Bearer ${process.env.TASKLIST_TOKEN}` },
    });
    const { data } = await response.json();
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import os, requests

    response = requests.get(
        "https://api.tasklist.example/lists",
        headers={"Authorization": f"Bearer {os.environ['TASKLIST_TOKEN']}"},
    )
    lists = response.json()["data"]
    ```
  </Tab>
</Tabs>

## When authentication fails

A missing or malformed header returns `401` with a JSON error body:

```json
{ "error": { "code": "unauthenticated", "message": "A bearer token is required in the Authorization header." } }
```

<Warning>
Tokens grant full access to the account. Keep them in environment variables or a secret manager, never in client-side code.
</Warning>
