Tasklist is a small HTTP API for keeping track of work: you create **lists**, add **tasks** to them, give tasks due dates, and mark them done. Everything is JSON over HTTPS and every request carries a bearer token.

## How it fits together

A **list** is a named container. A **task** belongs to exactly one list and carries a title, optional notes, an optional due date and a status that is either `open` or `done`. Deleting a list deletes its tasks.

<Note>
The hosted API is at `https://api.tasklist.example`. When you run the server locally it listens on `http://localhost:4000`.
</Note>
